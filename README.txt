G1 Studio and Stereo Ball Tracking — source export

Includes desktop application, stereo vision, camera relay, recording, trajectory and collision prediction, offline experiments, and local SONIC launcher scripts.

This is a snapshot of the existing installation, not a portable installer. Existing absolute paths and machine-specific calibration are preserved. Dependencies, pretrained YOLO/SONIC weights, robot URDF/mesh assets, Python environments, recordings and logs are not included. SONIC upstream code remains in the separately installed GR00T-WholeBodyControl repository.

See outputs/G1-Studio/README.txt and outputs/ball-trajectory/README.txt for usage and validation limits. vision/g1 contains the shared vision code referenced by those programs. experiments contains historical analysis scripts, including previous variants; some depend on excluded data files. SOURCE_MANIFEST.json lists source-file SHA256 hashes.
